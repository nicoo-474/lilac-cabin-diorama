# 紫色林间小屋 · 构建说明

**v2（2026-10-27 23:30 起）**：地台由 11×7.2 放大到 **16×11**，小屋移至 (0.30, 0.55)，
新增一条从门口延伸到前缘的**石板小路**（二阶贝塞尔中线 + 独立配色的平顶石板 + 路缘草簇），树木扩到 10 棵。
v1 小场景完整备份在 `backups/v1_small_20261027_2330/`。

Blender 5.2.2 LTS，Cycles(OptiX)，色彩管理 Standard（不用 AgX，否则纯色会被压灰）。

## 1. 运行方式（重要）

**桥接插件（dsh-blender-plugin）里绝对不能调用 `bpy.ops`。**
插件的命令队列是在主线程的 `bpy.app.timers` 回调里清空的，在其中执行
`bpy.ops.wm.read_factory_settings` / `object.select_all` / `object.join` /
`mesh.primitive_*_add` 会把主线程锁死，且异常不会返回，表现为"整个 Blender 完全不动"。

本项目因此改为：

- 建模：纯 `bpy.data` + `bmesh`，零 `bpy.ops`（清场、合模都自己写）
- 渲染：无头进程 `blender.exe -b --python build_scene.py`，stdout 直接看日志
- 桥接：`dsh.py`（同步）、`bx.py`（发完即走 + 写 build.log），只用于查看/交互

首次踩到的第二个坑：Blender 5.2 把 bevel 的 `miter_outer` 枚举从 `MITER_ARC` 改成了
`ARC`，旧参数抛 ValueError —— 在定时器里同样表现为"卡死"。`lilac.bevel_edges()` 已做兼容。

## v3（2026-10-28）

- **厚涂改为贴图**：不再有凸起几何。`lib/paintmap.py` 把底色 + 两档厚涂色栅格化成 16:11 的

- **风**：草地挂 Wave 修改器（顶点组按高度加权，根部不动，并给 `time_offset` 打关键帧才真正动）
  + 每簇树叶的正弦旋转关键帧（相位随机）。
- **落叶**：130 张单叶卡片手工打关键帧下落（相位错开），确定性、每帧可复现。
- **天空**：发光穹顶网格（对象坐标 Z → 渐变），避开世界着色器里 Generated/Incoming 方向不确定的坑；
  22 团云按相机视线高度摆放。

## 3. 灯光

1. 均匀光：World 的 Background，`Is Camera Ray` 分流——摄像机看深色背景，其余光线看均匀浅紫环境（强度 1.12）。
2. 一道直射光：单个 Spot（3.8°）+ 一支半透明光柱几何体。光柱设成 **只对摄像机可见**
   （`visible_diffuse/glossy/transmission/volume_scatter = False`），否则它会当作面光源给地面补光。
3. 室内：顶部暖点光 300W + 低位补光 90W + 纸灯自发光。

## 4. 关键实现

- `lib/lilac.py` 色板/材质/bmesh 工具；`bevel_edges()` 按部件传不同宽度与段数
- `lib/ground.py` 地台（顶面底/侧壁深两材质）、厚涂块、草簇、蓝花、**石板小路**（`build_path`）
- `lib/tree.py` 递归分枝（3 级、每级 2–4 叉），曲线放样用**平行传输坐标系**（否则树干会拧、出现台阶）；
  叶片为 alpha 贴图卡片，每簇沿枝轴拉长，簇内顶点法线取"以簇心为球心"的球面法线
- `lib/cabin.py` 玻璃茶室：柱/梁/窗棂/玻璃各自倒角；屋顶用四角点直接建板（不要用旋转，
  旋转支点错会让屋顶像盖子掀开）；茶壶/茶杯用旋转成型，不是球体堆叠
- 厚涂块：多谐波轮廓（非圆形）→ 挤出 → poke 起拱 → 只倒圆上沿，保持下沿利落

## v4（2026-10-28 晚）· 草的弯曲修正

**问题**：草在风里上下动，像被纵向拉伸。

**根因**：Blender 的 Wave 修改器位移方向是**物体局部 Z**，`use_x` / `use_y` 只决定波形
在平面上往哪个方向传播，不是位移轴。所以整个草甸被当成水面上下推拉。

**改法**（`lib/anim.py: add_grass_wind`）：换成几何节点 `GrassWind`，
`Set Position` 只加**水平**偏移，两个方向的 Z 分量都是 0，从结构上不可能有竖直位移。

- 权重 `(z/h)^1.7` —— 实测与悬臂梁挠度 `u²(3−u)/2` 几乎重合（u=0.5 时 0.308 vs 0.3125），
  整根草是弧线，不是"只有叶尖翻一下"。`Height` 取 0.72 m，超过即钳制为 1。
- 幅度 0.155 m，双向正弦：主向 `(0.94, 0.34)` 速度 0.16 rad/帧，副向 `(-0.42, 0.91)`
  幅度 34%、速度 1.31 倍 —— 叶尖走一个小椭圆，不是来回直线。
- 相位由空间噪声（物体坐标 ×0.30）给出，特征尺度约 3 m，**阵风成带状扫过**，
  前后排不同步；时间用 `Scene Time` 的 Frame 驱动，不需要打关键帧。
- 根部钉死：z=0 处权重为 0（实测最大 0.00035 m）。

**数值验证**（`check_wind.py`，333,060 顶点）：

```
FRAME   1  dz=0.000000  root=0.00035  tip_avg=0.0969  mid_avg=0.0281
FRAME   9  dz=0.000000  root=0.00035  tip_avg=0.1293  mid_avg=0.0396
FRAME  25  dz=0.000000  root=0.00035  tip_avg=0.1287  mid_avg=0.0389
```

dz 恒等于 0；中段位移约为叶尖的 30%，符合悬臂梁比例。

**Blender 5.2 的坑**：`mod["Socket_1"] = 0.15` 已经不能用（`id properties not supported
for this type`），几何节点修改器的输入只能写节点组接口的 `default_value`。

**顺带修掉的两个 bug**：

1. `save_as_mainfile` 原本在 `build_falling_leaves` **之前**，存盘的 .blend 里没有落叶，
   帧范围还是默认 1–250。现在保存挪到最后，落叶和 24fps/1–96 都进工程。
2. 不再默认渲动画：96 帧要 6.5 分钟，验证一次弯曲完全不需要。默认只出
   1 张主视图 + 4 个风相位的近景，20 秒跑完。

## v5（2026-10-28 晚）· 绿色主题

紫版完整备份在 `backups/v4_purple_20261028_2150/`（37 MB）。

所有颜色收进 **`lib/theme.py`**，两套预设 `PURPLE` / `GREEN`，用环境变量切换：

```
"D:\Blender\blender.exe" -b --python build_scene.py            # 默认绿色
THEME=purple "D:\Blender\blender.exe" -b --python build_scene.py
```

`T` 是只读属性访问器，键名写错会直接抛 `AttributeError`（不会静默变黑）。
各模块的常量（`ground.BASE` / `cabin.FRAME` / `tree.BARK_HEX` / `sky.SKY_TOP` …）都是
`T.XXX`，所以加主题只要再往 `_PRESETS` 里塞一个字典。`shot.setup_world` /
`add_fog` / `add_beam` / `sky.setup_sky` 的默认参数改成 `None` 再在函数里取主题值
（默认参数在 def 时求值，直接写 `T.FOG` 会把旧值冻住）。

**踩到的坑**：天空穹顶的渐变把物体坐标 Z 从 −210 映射到 −35，而这个俯视机位只看到
**MID → TOP 这两档**（HOR 根本进不了画面）。第一版把 MID/TOP 配成深墨绿，背景就成了
一片死气沉沉的墨绿。现在 MID `#7FB49B`（画面下缘）→ TOP `#B6DDC6`（上缘），
HOR `#E8F6E4` 留给更陡/更广的机位。云要比天空更亮才能显形：`#F2FBF0`。
